# 📚 Sistema Livraria Maria  
Projeto acadêmico para a disciplina **Prática Profissional em Análise e Desenvolvimento de Sistemas**.

Este repositório contém o código-fonte do sistema Livraria Maria, incluindo as funcionalidades principais de catálogo, carrinho, pedidos, pagamentos, avaliações e painel administrativo.

---

## 🛠️ 1. Requisitos para executar a aplicação

### ✔️ Softwares necessários

- **Node.js (versão recomendada: 18 ou superior)**  
  Download: https://nodejs.org/

- **Git instalado no computador**  
  Download: https://git-scm.com/

- **VS Code** (opcional, mas recomendado)  
  Extensão útil: Live Server
